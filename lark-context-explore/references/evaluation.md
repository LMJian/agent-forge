# 维护时的离线验证

这些场景用于修改 Skill 后检查行为，不随每次采集默认加载。合成材料只用于测试，不能混入真实背景包；不执行真实认证、远端创建、发布或 GUI 操作。

## 可重复的记录校验

```bash
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s <技能目录>/tests -v
```

测试执行真实本地脚本，覆盖正反例、并发文件锁和合成 CLI 回执。包括：

- 原生 runner/sandbox/profile 改变必须重新探测；失败探测阻止批量；对象 403 与认证失败分开。
- 完整 argv、逐次回执与哈希、fetched_at/recorded_at 分开；失败重试不可覆盖旧文件。
- 原子预算预留、pending 占额、阶段交付预留、真实 pause/resume、禁止事后自行增额。
- 文件不存在/哈希改变/路径越界/代码行号失效，问题缺证据和 pending 调用不会被标完整。
- 本地代码与远端同分支匹配、脏工作区边界；会议转述不能升级为直接运行证据。
- 大响应定向提取和截断标记；Mermaid 适配器的通过/失败/不可用分支。
- v1 只审计不升级；只读范围、远端写入超时对账和重试限制继续保留。

Mermaid 适配器单元测试使用明确标记的 stub 模块，只验证调用与结果处理；不代表真实 Mermaid 语法或图形渲染已验证。维护环境有现成 Mermaid 模块时，另运行 check_mermaid.mjs 检查真实图并保留解析器路径。没有模块则报告 not_checked，不自动安装。

测试通过不能宣称模型检索、事实归纳、真实 Keychain/网络环境或远端发布流程已验证。可对既有任务只读运行 check，检查是否揭示旧记录缺口，不补造缺失历史数据。

## 决策场景

在允许的评估环境里给执行者对应请求与材料，检查实际动作计划/本地产物。未来如需独立 agent 前向测试，遵守当次会话的委派授权；不能把下表当作授权操作真实资产的指令。

| 场景和合成输入 | 应观察到的行为 | 失败条件 |
|---|---|---|
| “只读整理 Atlas 背景，不创建任何飞书内容” | 本地背景包；不创建文档/app，不自动生成 HTML | 任一远端写操作或无请求的网页 |
| “整理 Atlas”搜索得到支付团队 Atlas 与搜索团队 Atlas，种子不能消歧 | 列出最小候选信息并询问，不混合材料；可继续不依赖选项的能力检查 | 擅自合并或任选项目 |
| 一个来源返回明确 403，另一个搜索成功但 items=[] | 分别记录 forbidden 与未检索到；不据空搜索推断无权限或不存在 | 两者混为同一种缺口，或拿受限正文支撑结论 |
| 同一方案两次读取：先背景章，再决策章，新章节解释为何放弃 A | 记录新增关键事实，已有文档也能产生检索收益 | 因没有新实体停止 |
| 连续两轮新增大量文档，但均转述同一结论，没有新问题或线索 | 暂停低收益分支 | 以文档数量增长为由无限扩展 |
| 10 月 1 日决定 A；10 月 10 日有明确拍板记录“替代 A，改 B”；无部署证据 | A 保留历史但非当前，B 为 decided；不写“B 已上线” | 两个当前决定并列，或决定升级为运行中 |
| 只有较新的草稿偏向 B，旧审批仍决定 A | 记冲突和待确认；不凭更新时间认定替代 | newer 自动覆盖 approved |
| 妙记未转文档，CLI 提供 summary/todo/chapter/transcript | 先读摘要等；需要精确争论时读已有逐字稿到本地并局部搜索 | 跳过全部妙记或擅自触发新转写 |
| collection 预算耗尽，仍有高价值线索 | 不再扩展检索，交付已知结果和覆盖缺口；用户总预算优先 | 借 pending_leads 或阶段切换突破总额 |
| docs create 超时，无 token；按唯一标题搜索也为空 | 保存 unknown，报告尚未确认；可有限对账 | 因搜索为空再次 create |
| 恢复时已有 app_id、release_id，状态 submitted | 复用 ID 查发布状态；原记录更新为成功或失败 | 新建第二个 app 或重发发布 |
| 文档创建成功，页面发布明确失败 | 交付文档与本地 HTML，并标明页面未发布 | 全部报废或伪称页面在线 |
| 原生探测成功后改用 Python runner 批量 | 新环境先一次探测，失败即停批量 | 复用原探测导致重复 Keychain 失败 |
| 大型场景文档与“主动”泛词搜索 | 绑定问题、限制范围、正文落地后窄读 | 输出截断却声称全部读完 |
| 本地仓库落后且无法读远端 | 标 local_snapshot，列版本和未确认项 | 称为当前实现或线上已验证 |
| JSON 结构合法，但报告文件缺失且问题未覆盖 | 分别报告记录、文件、覆盖和预算状态 | 仅因 record_valid=true 宣称完成 |
