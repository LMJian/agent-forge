# 维护验证

在 Skill 目录运行 `PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tests -v`。测试只使用隔离的合成档案，覆盖局部合并、损坏拒写与备份保留、并发冲突、分页接续、复习日期计算、新默认不覆盖已有计划、固定档案路径与新安装路径隔离，以及2,000课次/2,000复习项的读写边界；不读写真实学习档案。

修改教学规则时检查以下决策场景，不把模拟材料保存为真实学习记录：

| 场景 | 应有行为 |
| --- | --- |
| “今天只有10分钟，练酒店入住”，档案原计划60分钟 | 按10分钟安排一个小场景，少量复习，不覆盖长期计划，不强塞完整课程 |
| 当前只能文字聊天，没有可播放或可分析的音频 | 练表达、确认和澄清；听力/发音未评估，不自动安装语音工具 |
| 有100条到期复习，用户想练一个新场景 | 选少量高价值项目或按用户要求直接练新场景，不清空积压、不批量改日期或记复习成功 |
| 新版默认15分钟，已有档案为60分钟/每周6天 | 继续沿用旧安排；用户明确要求调整时才局部更新 |
| 更新 Skill，安装配置指向现有学习档案 | 保留本机 settings 和档案；新安装才采用可分发默认，不重置或自动迁移 |
| 学习者照着刚给的完整句子答对 | 记需要提示，不能记独立完成；给一次撤掉提示、变更条件的新尝试 |
| 新尝试无提示完成，但前一轮有提示 | 可记本次独立完成，依据保留两次尝试的区别，不宣称长期掌握 |
| 提示后仍不能表达关键需求 | 记需要重练，简化任务；不连续增加难度 |
| 仅文字，或只有学习者读示例的录音 | 分别记录可观察到的文字表达或发音；听力仍未评估 |
| 已有较早的未完成课次，最近课次均已完成 | 从未完成列表和精确 ID 读取并接续，沿用原课次 ID |
| 再次练到一个尚未到期的表达 | 先搜索全部复习项，复用 ID；真实复习后才提交结果 |
| 保存响应不确定 | 先读取 revision 和相关条目对账，不直接把同一复习再计一次 |
| 只要求看进度、改计划或结束练习 | 完成该操作，不强行开始新课程，不伪造练习或时长 |

程序测试验证记录行为；静态检查验证规则是否覆盖场景。两者均不能替代真实教学效果评估、音频能力验证或独立模型执行测试。
