# Codex Agent Rules

一份可复用的 Codex 全局 `AGENTS.md` 模板，用于约束 Computer Use 授权，并减少工具调用和长上下文造成的额度浪费。

它不是 Skill。Skill 只在匹配到相关任务时加载，而 `~/.codex/AGENTS.md` 会作为用户级规则在新会话开始时读取，更适合保存必须持续生效的工作约定。

## 包含的规则

- 每个任务首次使用 Computer Use 或 GUI 自动化前，说明具体用途并等待用户明确授权。
- 授权仅适用于已说明的任务和目的，不能从泛化任务指令或其他任务的授权中推断。
- CLI、API、Connector、MCP 或专用 Skill 能完成时，优先使用这些接口。
- 批量或并行外部请求前先做小范围的认证与网络探测，在相同任务和访问范围内复用结果；限制工具输出，避免重复读取大文件或输出完整页面结构和日志。
- 大段正文通过文件或结构化 API 传递；外部文档先在本地准备内容，集中应用更新，再窄范围回读已改部分。
- 同一路线失败两次后先诊断并更换方案，避免重复消耗。
- 区分空结果、超时、认证失败和权限拒绝；达到要求且必要校验通过后交付，保留影响结论的证据边界。

## 安装

如果还没有个人全局规则：

```bash
mkdir -p "${CODEX_HOME:-$HOME/.codex}"
cp AGENTS.md "${CODEX_HOME:-$HOME/.codex}/AGENTS.md"
```

如果已有 `~/.codex/AGENTS.md`，请把本目录中 `AGENTS.md` 的章节合并进去，避免覆盖原有约定。Codex 在新会话启动时读取全局规则，因此安装或更新后请开始一个新会话进行验证。

## 使用边界

这份模板降低无效上下文和工具输出，不能把模型额度消耗固定在某个数值。实际消耗仍受模型、推理档位、任务复杂度和其他共享额度任务影响。

项目目录中的 `AGENTS.md` 可能增加更具体的约定。发布或采用项目级规则时，应保留用户对 Computer Use 的授权边界。
